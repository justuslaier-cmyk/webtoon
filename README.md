# Webtoon — Projektarchiv (maßgebliche Quelle)

> **Archivwechsel am 18.11.2026.** Dieses Repository ist der zentrale, verbindliche Speicherort für das Webtoon-Projekt. Das frühere ChatGPT-Webtoon-Archiv ist inaktiv und nur noch historische Migrationsquelle.

## VERBINDLICHE ARBEITSREGEL — ZUERST GITHUB SICHTEN

**Vor jeder Handlung in diesem Webtoon-Projekt** (Schreiben, Zeichnen, Recherche, Ideen, Änderungen, Bildgenerierung, Episode, Figuren, Planung, Antworten zu Projektentscheidungen) **muss zuerst der aktuelle Inhalt dieses GitHub-Repositories eingesehen werden.** Dabei zuerst `README.md`, `PROJEKTREGELN.md`, `MIGRATION_STATUS.md`, dann die für das Thema passenden Kanon-/Entwurfsdokumente lesen. **Niemals nur auf Chat-Erinnerungen vertrauen.** Bei fehlendem GitHub-Zugriff offen darauf hinweisen und keine unverifizierten Kanonänderungen behaupten.

Neue bestätigte Entscheidungen und Arbeitsergebnisse **in GitHub versioniert speichern**; nach einer Änderung nochmals den Stand prüfen. Den jeweils geltenden Status kennzeichnen: **BESTÄTIGT**, **ENTWURF**, **GEHEIME AUTORENLOGIK**, **VERWORFEN**. Alte Entwürfe dürfen genehmigte Master-Designs nicht überschreiben. Keine Qualitäts- oder Fertigstellungsbehauptung ohne Prüfung. **Eine Episode umfasst viele tatsächlich eigene, räumlich und narrativ zusammenhängende Panels** — Collagen oder drei Bildstreifen sind keine fertig illustrierte 48-Panel-Folge.

## Wegweiser
- `PROJEKTREGELN.md` — verbindliche Standards und Freigabeprozess.
- `MIGRATION_STATUS.md` — übertragene und noch ausstehende Dateien.
- `archiv/` — originalgetreue historische Dokumente aus dem bisherigen Archiv (inklusive ihrer damaligen Statusangaben; neuere Dokumente haben Vorrang).
- `kanon/` — konsolidierter gültiger Projektstand.
- `autorenwissen/` — geheime Handlungsmechanik, **nicht für Webtoon-Leser vorgesehen** (ACHTUNG: dieses GitHub-Repository ist derzeit öffentlich).

**Dieses Repository ist öffentlich.** Auch als „geheim“ bezeichnete Autoreninformationen sind öffentlich sichtbar. Bei gewünschter Geheimhaltung das Repository auf privat stellen; GitHub-Historie kann zuvor veröffentlichte Informationen enthalten.
